# Reyan Ahmed — 3D Animated Portfolio

## Run in VS Code

1. Extract this folder.
2. Open it in VS Code.
3. Install/use **Live Server**.
4. Right-click5y `index.html` → **Open with Live Server**.

The site uses Three.js and Google Fonts from public CDNs, so keep an internet connection while previewing the interactive 3D background and typography. The theme toggle remembers your choice in the browser.

## Files
- `index.html` — page structure and content
- `portfolio.css` — responsive light/dark themes, layout, animations and scroll-reveal effects
- `script.js` — Three.js scene, particles, theme toggle, scroll progress, 3D text motion and mobile menu
- `reyan-photo.jpeg` — your uploaded photo
